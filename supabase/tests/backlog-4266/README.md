# BACKLOG-4266 — the AI-app connect notice is written with the exchange

Migration `supabase/migrations/20261123170000_backlog_4266_connect_notice_with_exchange.sql` replaces
`mcp_exchange_code`. The notice INSERT now runs in the exchange's own transaction, with no exception handler around
it. The exchange then requires that exactly one row was written, and raises MC004 if not. A failed or zero-row INSERT
rolls the whole call back:

- the code stays unused;
- the connection stays pending;
- the earlier connection is kept;
- no token and no notice are stored.
