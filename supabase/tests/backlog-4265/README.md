## What the calls check

- **Lock probe.** The first block after the state check, in a subtransaction that is undone, before any statement
  touches the 19 relations. It records which relation locks this session holds:
  - before;
  - after the migration's four REVOKE statements;
  - after an explicit `LOCK TABLE public.cloud_deal_messages IN ACCESS SHARE MODE`.

  The last row is the probe's own positive control: the reporter fails the call when it is missing or when a lock is
  held before the probe. The lock mode of the privilege change is not established until this has run.
- **Before the apply,** `c01_privileges`, `c02_statements_a_c`, `c14_statements_b` and `c15_sequence` run once and
  must FAIL (negative control).
- **Controls.** Each runs in a subtransaction that is undone. Controls that act as a role use `SET LOCAL ROLE` and
  assert `current_user`.

## Stop rules (for every call of this harness on a shared database)

1. **Reporter problems.** Any `NOT OK`, `problems=` above 0, `NOT_APPLIED`, `NOT_CAUGHT`, `CRASH`, `NEG_FAILED` or
   `transport:` line: STOP. Send nothing further: not the later stages, and not this file again.
2. **HTTP 200.** A `kt-sql: HTTP 200` line (or two status lines) means the call COMMITTED. STOP and escalate at once.
   Fixture rows may have persisted; count them by the fixture ids only.
3. **Non-zero `gone_or_changed`.** STOP. Do NOT re-send. A row that existed before the call was deleted or changed
   while the call ran. Either:
   - the call itself did it: a defect in the product or the harness; or
   - another session wrote during the call. Each statement sees a fresh snapshot, so the final check sees other
     sessions' commits.

   Writers that can do the second:
   - any AI-app call;
   - a token refresh;
   - the connect-notice sender;
   - an upload from a desktop;
   - the erase job;
   - a scheduled cleanup;
   - a sign-in.

   Report the table name and the count only, never row content. A re-run needs a written diagnosis first.
4. **Lock probe.** The positive control is missing, or a lock is held before the probe: STOP.
