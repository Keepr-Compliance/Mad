# BACKLOG-3547 harness — submission INSERT rule

Runs `supabase/migrations/20260927120000_backlog_3547_submission_insert_pre_review.sql`
— **the shipped file itself** — on a real Postgres, on top of the BACKLOG-3477
prelude (the checklist migrations production holds, then 3477), and records
what every control and every mutant did. `control-run.txt`, `baseline-run.txt`
and `mutant-run.txt` are the recorded runs' own output, unedited.

It is not in CI: CI has no database. The text tripwire that runs in CI is
`broker-portal/__tests__/migrations/submission-insert-pre-review-3547.test.ts`.
No file here has a `.test.` or `.spec.` infix.

**Nothing has been applied to production, and nothing here can reach it.**

## Running it

```bash
H=supabase/tests/backlog-3547/run.sh
export SSH_HOST=<ssh alias> PG_CONTAINER=<container name>   # values on the backlog item

bash $H gate        # backlog-3477's gate: schema-only venue, no checklist tables
bash $H baseline    # every control WITHOUT this migration: shows the defect
bash $H controls    # 9 controls, each in its own rolled-back transaction
bash $H mutants     # 12 mutants from lib/mutants.txt against every control
bash $H gate        # again: proves nothing leaked out of a transaction
```

Run under `bash`, not zsh.

## Prelude

```
BEGIN
  backlog-3477's prelude, unchanged (catalogue, 3473, 3535, 3474, 3476, 3477)
  -> backlog-3477/lib/fixtures-3477.sql
  -> lib/widen-commission.sql   (the four BACKLOG-3519 commission columns, no CHECKs;
                                 pg_temp.desk(), the desktop insert shape)
  -> 3547 (or a mutant of it) -> control
ROLLBACK
```

`baseline` (no 3547 migration) reds c00, c02, c03 and c04: the defect as filed.

## Mutants

Generated by `run.sh` from `lib/mutants.txt` by exact-string replacement on the
shipped file; a replacement that matches anything other than exactly once
aborts the run. Each prints `MUTATION APPLIED` with its first changed line.
